# Lumora

  Propósito
En las organizaciones modernas, existe una profunda brecha entre las políticas corporativas de bienestar y la realidad operativa de los colaboradores: asignaciones informales, reuniones consecutivas y sobrecarga de trabajo invisible que derivan en desmotivación y rotación no deseada. Lumora aborda este problema consolidando métricas objetivas de esfuerzo, un asistente conversacional asistido por Inteligencia Artificial (Lumi) y dinámicas de reconocimiento para mantener equilibrada la salud operacional y emocional de las organizaciones.
El propósito de este documento de Especificación de Requisitos de Software (ERS) es definir de manera detallada y formal los requisitos funcionales, no funcionales y las restricciones del sistema Lumora.
